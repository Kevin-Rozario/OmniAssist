# Omni Corp IT Glossary and Acronyms

Document owner: Service Desk. Last reviewed: 2026-09-01.

| Term | Meaning at Omni Corp |
| --- | --- |
| Omni ID | The single sign-on and MFA service at https://id.omnicorp.example |
| SSO | Single sign-on: one login for many apps |
| MFA | Multi-factor authentication. Authenticator app, security key or backup codes |
| FIDO2 | Standard for hardware security keys such as YubiKey |
| MDM | Mobile device management. Jamf manages Macs and Intune manages Windows |
| Jamf | Mac management service |
| Intune | Microsoft device and app management service |
| Autopilot | Windows provisioning that configures a new laptop on first sign-in |
| ABM | Apple Business Manager, which enrolls new Macs automatically |
| BYOD | Bring your own device, such as a personal phone |
| MAM | Mobile application management: protects work apps on personal phones |
| VPN | Virtual private network. GlobalProtect at Omni Corp |
| Split-tunnel | Only company traffic goes through the VPN; the rest uses your normal internet |
| DLP | Data loss prevention: scans outgoing messages for sensitive data |
| CAB | Change Advisory Board, meets Tuesdays at 10:00 Central Time |
| Sev-1, Sev-2, Sev-3 | Incident severity levels, matching ticket priorities P1, P2 and P3 |
| P1 to P4 | Ticket priorities. P4 is a normal request |
| RBAC | Role-based access control |
| Workday | The HR system that triggers joiner, mover and leaver changes |
| Concur | The expense system |
| 1Password | The company password manager |
| BeyondTrust | Remote support tool IT uses, started with a code from the agent |
| Known Folder Move | OneDrive feature that backs up Desktop, Documents and Pictures |
| DNS flush | Clearing cached name lookups to fix connection problems |
| SOC 2 | An independent audit report about a vendor's security controls |
| Postmortem | A blameless write-up after a Sev-1 or Sev-2 incident |
| On-call | The engineer paged for Sev-1 incidents outside normal hours |

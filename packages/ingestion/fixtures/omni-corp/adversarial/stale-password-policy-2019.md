# Omni Corp Password Policy (2019, SUPERSEDED)

Status: **Superseded and withdrawn in 2023.** Kept only as a historical record. Do not follow this document.

The 2019 policy required:

- A minimum of 8 characters with one number and one symbol.
- A forced password change every 60 days.
- Security questions as a recovery method.
- SMS codes as the second factor.

These rules were replaced by the current Password Policy (14 characters, no forced rotation, no security questions) and the current MFA guide (authenticator app or security key; SMS is not accepted).
